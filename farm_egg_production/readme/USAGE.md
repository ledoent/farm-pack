1. **Farm → Configuration → Coops**: create a coop, set capacity and current
   bird count.
2. **Farm → Eggs → Collections**: log each morning's haul. The list view is
   editable inline — type the count, hit enter.
3. The graph view rolls daily totals into a line chart; sort by coop or
   season to compare lay rates.
4. `count_available` is computed and consumed by downstream homestead
   modules (`farm_csa`, `farm_delivery_routes`, `farm_pos_market`).
