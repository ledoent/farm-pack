Daily egg collection log for homestead operators. Each `farm.egg.collection`
row is one coop on one day, splitting the haul into broken/cracked,
kept-for-home, and available-for-sale. Designed for the persona that wakes
up, goes to the coop, counts what's in the basket, and types the number in.

One row per coop per day is enforced; subcounts cannot exceed the total.
Coop kanban shows last-7-day total — useful for spotting drops in lay rate
before they become a hen-health problem.
