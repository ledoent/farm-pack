**Farm → Fields** lists every plot. *New* to add: name, code (used on signage),
acres (manual; the future `farm_field_geo` will compute from polygon), current
crop. The Organic flag is tracked in the chatter for audit trail.

For multi-season records, link `farm.planting` entries to the field. The kanban
view supports per-card color so you can flag plots that need attention.
