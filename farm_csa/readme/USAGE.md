1. **Farm → Configuration → Tiers**: create your share offerings. Each tier
   needs a linked product (used for invoicing later).
2. **Farm → CSA → Subscriptions**: when a member signs up, create a
   subscription pointing at their tier and chosen delivery method.
3. **Farm → CSA → Boxes**: each week, create boxes for active subscriptions
   (manual in MVP; auto-generation arrives in v1 with the
   `farm_delivery_routes` integration). Add lines for what's in the box.
4. **Calendar view on Boxes** shows the week's deliveries at a glance —
   colored by state.
