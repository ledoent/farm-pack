**Farm → Harvests** logs each pick. The fastest path: open a planting and create
a harvest from its smart links — field + crop auto-fill from the planting.

For standalone or retroactive entries, create directly: pick a field, a crop, a
date, the quantity + UoM (pound is the default for produce). Optionally tag a
quality grade (A / B / C / Compost) to feed downstream pricing tiers.

Group by crop or season to see yield totals across plantings; the list view sums
`Total` across selected rows.
