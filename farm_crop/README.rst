Catalog of crops grown on the farm. Seeds with 18 common US small-farm
crops at install (tomato, lettuce, kale, sweet corn, etc.) and lets
farmers add their own.

Used by ``farm_field`` (current crop on a field), ``farm_planting``
(what's being planted), and ``farm_harvest`` (what's being harvested) —
but those modules don't ship together; this catalog is the single source
of crop identity.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Usage
=====

Browse the seeded catalog at **Farm → Configuration → Crops**. To add a
custom crop: hit *New*, fill name + category (vegetable, fruit, grain,
etc.), optionally latin name + botanical family (helps with rotation
planning) + days to maturity.

Crops referenced from ``farm.field``, ``farm.planting``, and
``farm.harvest``. Archive unused entries via the Active toggle rather
than deleting.
