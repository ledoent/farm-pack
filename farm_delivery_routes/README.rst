Plan and execute weekly delivery routes for homestead operators:

- ``farm.dropoff.point`` — a place to leave a box (porch, pantry, market
  booth, workplace) with instructions and optional contact partner.
  Inherits ``farm.gps.point.mixin`` for optional WGS84 coordinates.
- ``farm.delivery.route`` — one route on one day: driver, ordered stops,
  state machine (planned → in_progress → completed). Cancelling a route
  is non-destructive.
- ``farm.route.stop`` — a stop on a route, referencing a drop-off point
  and carrying a package count + per-stop note. Stops can be
  individually marked delivered/skipped; finishing the route
  auto-delivers any stops still pending.

Usage
=====

1. **Farm → Delivery → Drop-Off Points**: register the places you
   regularly leave product — neighbor porches, the wellness pantry,
   market booths. Optional contact partner, free-text address, free-text
   instructions.
2. **Farm → Delivery → Routes**: each route is one day's drive. Pick the
   stops, drag-reorder, set package counts. The route's printable PDF is
   a pick list (arrives in v1).
3. Click **Start Route** to lock in stops. Tick stops delivered/skipped
   from the road. **Finish Route** auto-delivers everything still
   pending.
