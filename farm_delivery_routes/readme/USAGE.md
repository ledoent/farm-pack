1. **Farm → Delivery → Drop-Off Points**: register the places you regularly
   leave product — neighbor porches, the wellness pantry, market booths.
   Optional contact partner, free-text address, free-text instructions.
2. **Farm → Delivery → Routes**: each route is one day's drive. Pick the
   stops, drag-reorder, set package counts. The route's printable PDF is a
   pick list (arrives in v1).
3. Click **Start Route** to lock in stops. Tick stops delivered/skipped
   from the road. **Finish Route** auto-delivers everything still pending.
